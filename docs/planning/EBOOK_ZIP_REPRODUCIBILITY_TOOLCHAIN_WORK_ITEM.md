# WI-0018: Inkompatible ZIP-Toolchain bei Fixture-Reproduktion eindeutig ausweisen

Status: REJECTED — SEPARATE CANONICAL DECISION REQUIRED

Stand: 2026-09-13

Artifact: WI-0018

Eine Validatoränderung würde die kanonische Toolchain stillschweigend
festlegen. Der Gegenstand wird daher nicht umgesetzt. Die bestehende
bytegebundene Evidenz bleibt unverändert; eine spätere Entscheidung muss
Toolchainbindung, neue semantische Fixture-Version oder eine explizite
Beschränkung auf die bestehende CI-Laufzeit getrennt wählen.
